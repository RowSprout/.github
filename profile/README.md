### What RowSprout does

RowSprout is a WordPress plugin that turns one template and a table of rows into real
WordPress pages: a page per town, service, branch, product or vacancy, all from a single
design. Change the template once and every page follows.

### How it works

1. **Design one template** in the block editor, Elementor or WPBakery, with placeholders where content should change.
2. **Add your rows**: type them in, or import them from a CSV or Excel file, a URL or a Google sheet.
3. **RowSprout generates a real page for every row**, with its own URL, title, content and SEO settings, in the background.

Along the way: child templates that reuse a parent's rows, "If / then" content per row,
a Grid of all pages, and support for Rank Math, Yoast SEO, SEOPress and The SEO Framework.
[RowSprout Pro](https://rowsprout.com/pricing/) adds Smart Generate, planning, WPML,
more field types, scheduled sync from a sheet, file or JSON feed, and WP-CLI and MCP for
scripts and AI agents.

### Source code and documentation

The free plugin is open source: [RowSprout on GitHub](https://github.com/RowSprout/RowSprout).
Install it from the [WordPress.org plugin directory](https://wordpress.org/plugins/rowsprout/)
or download the latest [release](https://github.com/RowSprout/RowSprout/releases/latest).
The documentation, including the hook reference for developers, is at
[docs.rowsprout.com](https://docs.rowsprout.com).

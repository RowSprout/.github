### What RowSprout does

RowSprout is a WordPress plugin that generates SEO landing pages from a single template.
You design the page once, add placeholders, and RowSprout fills them with parent and
child data based on the URL, so every location, service or product gets its own page.

### How it works

1. **Design one template** in WordPress, with placeholders where content should change.
2. **Add your data**: parent and child items, such as regions and cities.
3. **RowSprout grows a page from every row** and serves a unique page for every URL.

### Source code

The free plugin is open source: [RowSprout on GitHub](https://github.com/RowSprout/RowSprout).
Download the latest version from the [releases](https://github.com/RowSprout/RowSprout/releases/latest)
or, once approved, from the WordPress.org plugin directory.

# Security policy

We take the security of RowSprout and its users seriously. Thank you for helping us keep it safe.

## Supported versions

Only the latest release receives security fixes. Please make sure you can reproduce the issue on the newest version before reporting.

| Product | Supported |
|---|---|
| RowSprout (free, WordPress.org), latest 3.x release | ✅ |
| RowSprout Pro, latest release | ✅ |
| Older releases | ❌ |

## Scope

- The **RowSprout** plugin (WordPress.org)
- The **RowSprout Pro** add-on
- The licence and update service at `license.get-wefta.com`
- The website `rowsprout.com`

Vulnerabilities in WordPress core, themes or other plugins are out of scope; please report those to their own maintainers.

## Reporting a vulnerability

**Please do not report security issues through public GitHub issues, the WordPress.org support forum or social media.**

Email **[contact@rowsprout.com](mailto:contact@rowsprout.com)** with the subject line `Security:` followed by a short title. Please include:

- the affected product and version
- a description of the issue and its impact
- steps to reproduce, or a proof of concept
- your name or handle, if you would like to be credited

## What to expect

- We acknowledge your report within **3 working days**.
- We keep you informed while we investigate and work on a fix.
- We aim to release a fix within **30 days** for confirmed issues, sooner for critical ones.
- Once a fix is available, we credit you in the changelog, unless you prefer to stay anonymous.

Please give us reasonable time to fix the issue before disclosing it publicly, and do not access or modify other people's data while testing.
